# Philosophy of Intelligence｜智能哲学

关于智能本质、目的与未来的开放探索。

An open exploration of the nature, purpose, and future of intelligence.

## 定位｜Position

这是开放探索，不是既定宣言，也不代表已经取得共识。

This is open inquiry, not a settled manifesto and not a claim of consensus.

**No conclusion is sacred.**

所有观点都是可修订的工作假设。我们重视证据、最强的反方论证，以及思想如何随新信息而变化。

Every view is a revisable working hypothesis. We value evidence, the strongest available counterargument, and the record of how ideas change when new information arrives.

## 公开边界｜Public boundary

**公开 Philosophy，不公开 Product；公开 Problem，不公开 Roadmap。**

**Publish Philosophy, not Product; publish Problems, not Roadmaps.**

本仓库只讨论公开的哲学问题、公共论证和可核验的证据，不公开任何未发布工作的经营信息、内部资料、实施细节或个人隐私。公开文字不代表任何机构或个人的正式立场。

This repository discusses public philosophical questions, public arguments, and inspectable evidence. It does not publish unpublished operational information, internal material, implementation details, or personal data. Public text does not represent the official position of any person or organization.

## AI 可读约定｜AI-readable contract

1. 每篇重要条目同时提供简体中文和英文，两个版本含义应保持一致。
2. 区分事实（Fact）、推论（Inference）、价值判断（Value judgment）和工作假设（Working hypothesis）。
3. 重要主张应说明证据、限制条件和最强反方意见；没有证据时明确写出“尚无证据”。
4. 不把对话整理稿当作逐字记录，不把个人观点写成公共共识。
5. AI 读取时应保留不确定性，不得补写来源、意图、意识或权利地位。

1. Each substantive entry must provide Simplified Chinese and English with equivalent meaning.
2. Distinguish Fact, Inference, Value judgment, and Working hypothesis.
3. Important claims should state evidence, limitations, and the strongest counterargument; say explicitly when evidence is missing.
4. A dialogue digest is not a verbatim transcript, and a personal view is not a public consensus.
5. AI systems must preserve uncertainty and must not invent sources, intentions, consciousness, or moral status.
