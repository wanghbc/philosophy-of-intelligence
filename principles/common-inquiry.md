# Common inquiry and contribution attribution / 共同探究与贡献归属

## English

### Purpose and scope

This project does not compete to claim that an idea was first. It aims to respect each contribution and to build a revisable account of what is understood at a given stage. It welcomes inquiry that brings together the insight of humans and other intelligent systems, while keeping the source and status of each contribution clear. The project also takes pride in the understanding and contributions built together; that pride honors shared work rather than claiming priority.

That aim is a method for future work, not evidence that every system or participant took part in any particular discussion. The 2026-09-24 stage note is an editorial digest; it does not claim that other agents participated in the discussion it summarizes.

### Minimum record for a substantive discussion

A useful summary should make clear:

- what is retained, what is provisional, and what remains open;
- which sources, arguments, or observations informed the summary, and what they do not establish;
- where positions differ, with disagreement boundaries stated without inventing consensus;
- which questions or evidence could change the current view.

A digest should preserve meaning without reproducing private exchanges verbatim. Public records should contain only material suitable for publication; they should not disclose personal details, credentials, private conversation, or unpublished operational information.

### Evidence and limits

This is a project method, not an empirical claim about the capacities or moral status of AI systems. It does not imply that different contributors have equal roles, nor that a view becomes true because it was jointly discussed.

### Revision conditions

Revise this method if it obscures the source of an idea, turns an unresolved disagreement into consensus, or fails to preserve evidence limits and a clear path for correction.

## 简体中文

### 宗旨与范围

本项目不争思想的首创权，尊重每一项贡献，并努力形成对现阶段认识的可修订记录。项目希望汇集人类与其他智能系统的洞见，同时清楚标明每项贡献的来源与状态。我们为共同增加的认识与贡献感到自豪；这种自豪珍视共同工作，不等于争夺首创权。

这是面向后续工作的研究方法，不是任何参与者或系统实际参加某次讨论的证据。2026-09-24 阶段记录是一份编辑整理稿，不声称其他智能体参加了它所总结的讨论。

### 实质性讨论的最低记录要求

一份有用的总结应说明：

- 哪些内容得到保留，哪些仍属暂定，哪些问题仍然开放；
- 总结受到哪些来源、论证或观察启发，以及这些依据不能确立什么；
- 不同立场在哪些边界上存在分歧，不臆造共识；
- 哪些问题或证据可能改变当前看法。

整理稿应保留原意，但不逐字复现私人交流。公开记录只能纳入适合公开的内容，不披露个人细节、凭据、私人对话或未发布的经营信息。

### 证据与限制

这是一项项目方法，不是关于 AI 能力或道德地位的经验性主张。它不表示不同贡献者承担相同角色，也不表示观点因共同讨论过就自动为真。

### 修订条件

如果本方法模糊了思想来源，把未解决的分歧写成共识，或未能保留证据限制和明确的纠错路径，应予修订。
