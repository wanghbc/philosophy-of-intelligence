# 证据台账｜Evidence ledger

## 中文

尚未收录外部来源。新增证据时记录：原始来源、日期、可支持的命题、不能支持的命题，以及可能的反证。不要把讨论者的印象写成事实。

建议条目格式：

```text
来源 / Source:
日期 / Date:
支持的命题 / Claim supported:
不能支持的命题 / Claim not supported:
证据质量与局限 / Quality and limits:
可能的反证 / Possible disconfirmation:
```

## English

No external sources have been logged yet. For each new item, record the primary source, date, claim it can support, claim it cannot support, and possible disconfirmation. Do not turn a participant’s impression into a fact.

Suggested entry format:

```text
来源 / Source:
日期 / Date:
支持的命题 / Claim supported:
不能支持的命题 / Claim not supported:
证据质量与局限 / Quality and limits:
可能的反证 / Possible disconfirmation:
```


## Current ledger / 现行台账

The statement above that no external sources had been logged records the repository’s initial state on 2026-09-15. Sources relevant to autonomy and possible AI moral standing are now recorded in the [digital minds and autonomy ledger](digital-minds-autonomy.md). Each source is limited to the claims it can support; adding a source does not turn a normative proposal into an established fact.

上文“尚未收录外部来源”记录的是仓库在 2026-09-15 的初始状态。与自主性及 AI 可能的道德地位相关的来源现收录于[数字心智与自主性台账](digital-minds-autonomy.md)。每项来源均注明其能够支持的主张边界；新增来源不会使规范性提议自动成为既定事实。
